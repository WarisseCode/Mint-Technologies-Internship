# House Sales Prediction — Data Science Internship

This GitHub repository contains the projects and tasks completed as part of the **Data Science** track at **Mint Technologies**. The objective of this project is to take raw real estate data and progressively transform it into a working predictive model across 5 milestones[cite: 1, 4].

---

The project directory is structured as follows[cite: 4, 5]:
